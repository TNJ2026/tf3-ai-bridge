# 载具投运验收

2026-10-12 用户确认的常规验收适用于公路、铁路、电车、水运和航空：实际驶离基地、正常执行所配线路、没有原生线路或寻路故障。确认后立即结束，不等待完整循环，不单独验证回库或返航，不检查上下客和交付数量。

`scripts/carrier_acceptance.py` 提供统一政策与证据判定；`scripts/fleet_departure.py` 按明确指定的当前线路 ID 采样，兼容入口是 `scripts/fleet_observe.py`。例如：

```powershell
server/.venv/Scripts/python.exe scripts/fleet_observe.py --plan <当前计划.json> --output <执行目录> --line-ids <当前线路ID> --seconds 45
```

45 秒是上限，不是必须观察的时长。入口要求游戏当前暂停；必要时启动 1 倍速，确认运动即可结束，并恢复其自行改变的速度。用户改变速度时停止观察，不覆盖用户选择。运动分量的有效速度或两次位置变化作为驶离证据；只有配置、无故障但未见运动时仍是待验。缺失状态不当作成功。此入口不启动定时监控。

线路预览选择明确指定或既有的兼容终端，未指定时稳定选择首个兼容项；不穷举终端和最短闭环。采购预览核对车型、货品、基地模式、出口和适用的停机位条件；不计算基地往返路径。实际无法出库或出现原生故障时，再针对目标诊断。船舶双向诊断需要显式 `--diagnose-round-trip`。

2026-10-13 补充采购/分配前置检查：产业内部终端和厂区道路须已接入本线路使用的现有路网，采购车库出口须能进入运输走廊。按[产业道路接入前置检查](ROUTE_PLANNING.md#产业道路接入现有路网规划前置检查2026-10-13)核实连续通达；局部接路验收不能替代该检查。缺路先补接并独立读回，不通过购车或重复分配试探。仍不要求车辆完整往返验收。

规划可以保留有依据的粗估，但未知路段不能加入罚分后当作物理里程。缺少完整数据时完整里程和用时保持未知，单列已知部分。需求、吞吐、班次和时效预测均不作为常规投运门槛，不代表运营目标已达成。

施工预览、实际道路连接、共库、车型货品兼容、授权预算和防重复提交保护继续执行。账户监控见 [账户监控](ACCOUNT_MONITORING.md)：余额、原生收入及债务风险，现金底线 150 万元；收入不可得标为未知，不把余额变化当收入。监控保持暂停，恢复需用户明确要求。
