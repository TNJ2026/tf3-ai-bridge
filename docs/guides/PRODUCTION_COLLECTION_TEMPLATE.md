# 四设施生产集合

2026-10-05 用户确认：以当前显示的生产集合为准，只保留直升机场、仓库、货车站、道路维护设施。客车站、公路车库属于旁边的城市集合，不纳入生产模板。城市仍用六设施模板，捕鱼港口不变。

## 当前配置与捕获依据

- 配置：[production.json](../../config/planning_templates/production.json)，版本 `production-displayed-four-facility-v5`，执行模式 `joint`。
- 布局证据：[独立生产集合捕获](../../exports/current_two_collections_20261005/template_comparison/production_capture.json)。保留四座设施的相对位置、朝向及模块；捕获编号仅作历史证据，不用于施工。
- 直升机场使用自身两个平台；仓库包含四通用、两液体模块；货车站包含六通用、三液体、三平板平台及出入口。
- 五段组内道路采用 `country/country_new_medium`（中型乡村公路）。资源样式名称包含 `country_new_large.street`，以实际模板映射为准，不能按文件名猜路型。
- 排除相邻城市设施、外接公路和设施自带入口道路。新址外接路与集合同步设计，实际入口由原生提案重新解析。

源现场道路与目标路型不同。模板保留维护设施吸附点到道路中心约12米的观测距离并标记须原生验证；这不是所有路型的通用偏距。占地与升级预留含估算，须按旋转后的全组设施、道路和扩建范围复核。

## 选址与复用

放在陆上生产点附近，不设固定最小或最大距离，不套用城市建成区外500米退距。优先选连续平地，在地形可行等级相同时缩短真实公路接驳，再比较货站到生产点的直线距离；不能为细微坡度改善明显远离生产点。仍避开城市建成区及扩张方向，并核对碰撞、噪声污染、升级空间、覆盖和往返通路。

优先评估已有集合复用。城市与生产点中心距离严格小于3000米时，按[共用规则](GROUPED_CONSTRUCTION_WORKFLOW.md#无限资金模式的默认集合选址)评估城市集合共用；不按生产点数固定新建。仓库不会自动向工厂集货或配送，仍需另行规划货车接驳。线路和车辆依各自授权执行。

## 批量执行与验收

使用当前模板生成布局、执行清单和依赖，先离线预检，再按新址实际地形进行设施、组内路及外接路的联合可行性检查。通过后按依赖单次提交、读回验收；异常停批，不自动重发。

验收包括四设施位置、朝向和模块，公共道路及货车站双向通路，机场实际道路链接，机场与货车站共同覆盖同一仓库库存，仓储容量，以及道路维护组件和路侧位置。没有组内客车站，不执行城市模板的客车站—机场换乘验收；这不豁免机场接路或其他验收。

模板及配套角色校验、提案编译和规划回归共42项离线检查通过。四设施中型乡村公路模板尚未完成新址原生施工与运营验收，不把离线结果当作施工许可或长期模拟安全证明。

## 已建集合与历史模板

此前娄底农场旁按六设施建成的集合保留，更新模板不自动拆除、迁移或重建。其施工记录和未完成验收项继续保留。

[旧双坪生产模板](PRODUCTION_HELIPAD_TEMPLATE.md)只供追溯。捕获工具 `--profile production` 选择当前四设施；`--profile legacy-production` 仅用于旧双坪现场。邻近设施较多时仍须确认成员和组内道路，不能仅凭“每种角色最近一座”判断集合归属。

## 捕获成员与验收缺项检查

捕获可用 `--members <JSON文件>` 提供角色到当前实体ID的映射，用 `--road-ids <ID...>` 指定组内公共道路。相同角色存在多个候选时拒绝按最近距离自动选择；指定实体必须在本次调查范围内且资源、用途匹配。新捕获在选择组内道路之前不能编译模板，避免复制相邻集合的公共路网。

联合及道路先建入口将冻结规格传入验收：缺少设施角色、组内道路证据、共库结果、任一方向车辆路径或维护结果均拒绝通过。没有客站属于不适用；有客站却缺少换乘证据属于失败。暂缓步行验收不再暂缓机场实际道路链接。失败原因写入 `acceptanceFailures`。
