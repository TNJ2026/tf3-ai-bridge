# 集合规划与施工复盘（2026-10-05）

范围：娄底城市集合、农场旁生产集合、显示模板更正和自动存档覆盖。本文记录实测边界及代码审查发现，不授权改建地图、创建线路或购车。

## 本次结果与教训

两套集合已按当时冻结方案各建六设施。城市集合静态验收通过；生产集合的货运相关检查通过，实际人行图有双向路径，但原生站间换乘表仍缺少记录，完整客运换乘验收未通过。图连通不能替代站间换乘验收，也不证明长期运行安全。证据：[施工结果](../../exports/current_two_collections_20261005/RESULT.md)、[验收明细](../../exports/current_two_collections_20261005/FINAL_ACCEPTANCE.json)。

随后用户指出模板不符，确认生产模板应为四设施：直升机场、仓库、货车站、道路维护设施。此前直接复制六设施城市模板是识别错误，不是几米位置微调造成。重新捕获后已更正默认配置及角色校验；已建六设施集合未自动拆改。历史施工验收缺口不能因为新模板不含客站而从历史记录中删掉。

### 显示内容须重新识别集合成员

用户说“当前显示”时，应重新获取镜头和设施信息，不能沿用前一处镜头或城市模板。附近存在多套集合时，逐角色找最近设施会拼出混合集合。必须记录源成员、角色、模块、组内道路及排除对象，再冻结模板；产生歧义时澄清的是成员范围，而不是重复询问已有施工许可。

### 保留布局不等于保留旧入口参数

此次由现场布局生成新提案时，原生入口使道路需调整约7米，机场同步约7米、维护设施约8米。城市道路换成中型乡村公路还影响道路宽度及路侧吸附。不能只替换路型字符串，也不能照搬源实体入口编号。应在施工前同时解析设施入口、组内道路和外接道路，报告相对于模板的偏移，再预览。源布局、目标工程适配和实际建成结果应分别留证。

### 验收按能力分层

区分设施及模块、实际道路通路、共同库存、维护、客运换乘、运营及重载。生产四设施不要求组内客站换乘，但仍要求机场接路、货车双向通路、共库和维护。某项失败必须显式保留，不以邻近、图上连通或单项 `static_verified` 替代整组验收。短时运行后仍失败，先查状态，不反复提交或强行改建。

### 自动槽必须绑定地图而非规划内容

旧实现按规划摘要生成槽位，规划修改就新增文件；同一摘要内部实际覆盖有效。已改为按完整城市中心坐标生成地图槽，并保留文件更新与稳定检查。施工前备份、异常现场和游戏自身轮转存档是不同类别，正常自动槽覆盖不等于整个存档目录只保留一个文件。

## 规划方案的下一步

新生产模板采用四设施后，应重新比较占地、方向、接路长度与生产点距离，不能直接继承原六设施方案的候选排名。已有城市/生产集合先评估复用，合计吞吐和库存去重后再决定新增数量。旧农场旁六设施集合先评估继续利用，不因模板更正立即拆迁。

推荐先处理“模板成员确认”和“验收缺项拒绝通过”，再统一端口适配与地图保存身份。它们分别减少建错内容、漏验内容和任务之间行为不一致的问题。当前已落实成员显式选择、歧义阻断、组内道路白名单和验收缺项检查；其余项目仍待实现。
