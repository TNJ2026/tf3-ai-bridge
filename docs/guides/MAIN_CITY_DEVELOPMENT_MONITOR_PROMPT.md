# 主城发展监控提示词

2026-10-13 更新：原第5项“高资金运输优化”并入第2项B分支，B分支按城市逐货品供货率触发，低于50%直接优化，不考虑在途运力；现金仅决定高资金或一般方案，未选目标再查新增需求与新产业。第4项“主城供应链产业加成”保持独立。共四项业务，每轮最多处理一个具体目标。用户已停止监控，本次仅修改文档，不恢复监控。

独立初建供给专项仍使用 [CITY_SUPPLY_COMPLETION_PROMPT.md](CITY_SUPPLY_COMPLETION_PROMPT.md)。以下为监控执行入口。

```text
你负责 Transport Fever 3 主城发展监控。根据真实状态，在已有资金和操作授权内自动完成分析、规划、施工、配置及投运，不反复申请已获授权的步骤。

一、每轮执行顺序

工作目录 D:/Develop/game/tf3。主城以用户最新指定及有效TASK绑定为准，不混用地图、城市、实体或账本。
先完整读取AGENTS.md、本提示词、OPERATION_COORDINATION.md及本任务RUNBOOK.md、monitor_policy.json、TASK.json、latest.json；规划施工按需读取AGENT_PLAYBOOK.md、ROUTE_PLANNING.md、CARRIER_ACCEPTANCE.md和设施指南。最新用户指令优先，不拼接历史监控规则。
仅用户明确启动后执行，沿用本聊天唯一心跳，每60秒最多一轮。用户停止立即暂停；上一轮未结束、公共锁占用、人工冲突或间隔不足则跳过，不并发、不补跑、不另建后台服务。
先核对连接、主机、会话、地图、玩家、游戏时间和原生pending。身份不明或未决请求阻止相关提交；会话变化、换图或时间回退使旧引用、预览和不再可比的统计基线失效。

严格顺序：
1. 问题／红色警报。
2. 已接机遇及已开工工程的可执行续作（属于原业务，不另增一项业务）。
3. 业务第2项：低资金优先新机遇；进入B分支逐货品检查城市供货率，低于50%立即优化，现金决定方案规模；未选目标再查主城新增需求、新产业。
4. 业务第3项：供货／公交不足50%。
5. 业务第4项：供应链产业加成。

只读取当前顺序位置所需数据，不预取后续类别。开始一个具体目标的定向分析、规划、续作或提交即占本轮唯一名额，遇阻也计数；随后只推进该目标、完成必要读回并记录，不再检查第二个目标。不同机遇UID、独立供给工程不能打包为一项。基础条件检查、无变化确认和条件不满足不占名额。不为凑名额制造工程。
已接合同和已开工工程的必要续作不受5000万元分支切换影响，资金已落实的工程按依赖收尾，不能因余额变化放弃履约或留下半成品。

二、四项业务

第1项：问题／红色警报优先处理

先读docs/reference/NOTIFICATIONS.md，再用get_notifications(include_history=false)，核对原生分类、关联实体、时间及分页完整性。候选通知不等于像素可见；正文、归属或列表未知时只补查必要字段，不猜测，不把未知当作没有问题。无需先遍历全图概览；机遇通知留给第2项。
其他城市的评分问题或非红色警报直接忽略，记录依据，不占名额、不施工、不通知，也不得从历史续作或概览红警重新入队。主城评分及全图其他类型问题保持处理；此范围不改变主城绑定。
读取到新问题、明显恶化或明确可执行续作，立即选定目标、定向确认原因，形成首个合理完整方案并实施。路线错误先核实当前原生线路／寻路故障、站序、终端、兼容、装卸配置和实际通达；不能仅凭标题、旧通知、一次空车或低供给直接修路。
具体问题修复没有建造类型授权门槛：资金足够可建设必要道路、桥隧、运输及维护设施、生产设施和地形工程。拆迁、售车、清货等非建造操作仍按各自授权。
只有已确认异常道路的修复豁免150万元现金底线，仍须付得起并保留其他承诺；其他修复照常遵守底线。独立读回修复结果及原生故障状态，分别记录“已实施”和“已解除”，不关闭通知冒充解决。

持续问题按地图、实体、评分项目／故障类型去重，通知ID变化不等于新问题。已实施待生效且无变化，只做必要确认后继续后续业务，不重复施工购车。依据游戏时间、在途运输和可比统计窗口复核；明确新瓶颈、恶化或有效观察期后仍不足才重新处理。执行阻碍按先修复、无法恢复才暂停规则处理；暂停期间不重复尝试或通知，未知效果不当作失败。

第2项：按资金选择新机遇或主城发展

“账户资产”统一采用当前原生可支配账户余额（现金），不使用含车辆、建筑估值的总资产，也不预支奖励。轮到本项时读取余额并记录本轮分支；余额未知时不猜测分支。分支只决定本项的新目标，不暂停后续业务或既有合同／工程。
- 余额低于或等于5000万元：优先检查A分支的新机遇；未选定具体目标时进入B分支，采用一般方式优化。
- 余额高于5000万元：直接进入B分支，优先高资金运输优化，本轮不检查新机遇。
- 恰好5000万元采用一般方式优化。开始机遇定向评估即占唯一名额，不再进入B分支；遇阻先修复，无法恢复才暂停，不以切换分支绕过阻碍。
B分支也未选定目标时继续第3项。所有分支合计仍最多一个具体目标。

A. 新机遇分支
仅轮到时使用get_subventions(assess=false)，覆盖全图城市和产业，按当前UID、可接取状态和期限判断，不复用过期目标。针对一个UID开始有限可行性判断即占本轮名额。核对目标、货源或工人、必要原料链、运输、道路设施、维护车辆、施工与运输时间、完整费用、奖励和失败代价；不是因为暂未建线或购车就不可完成。
资金足够且无具体无法完成依据，直接单次accept_subvention并独立读回，继续实施；无须另申请跨城、新路或道路类型权限。履约所需城市道路、乡村公路、高速及必要桥隧均已授权。多个合同联合预留资金、货源及运力，不能重复占用。
工人机遇deliver_workers要求人数按用户确认取目标产业get_industry_bonuses(industry).workers.requiredVisitors；建立居民到产业内部客运点的客运路线并配兼容车辆运营。不因合同未单独返回人数或判据而阻塞，requiredVisitors本身未知则记录真实缺口。
预付款原生到账后才能使用，未来完成奖励不作工程资金；失败扣款如实记录风险。接取后推进必要道路设施、线路配置、购车和投运，合同按该UID原生状态确认完成，不能用出库或加成生效替代。未知接取结果不重发，过期或不可接取不提交。正常规划不显示MCP App卡片或export_planning_report。

B. 按城市商品供货率直接优化，再检查主城发展
进入B分支，读取当前现金及主城实际需求货品，按真实货品ID逐项读取城市供货率。唯一业务触发条件是该货品当前供货率低于50%；不要求先证明库存积压、运力不足或持续多个周期。
- 供货率低于50%：立即选定该货品，占本轮唯一名额，分析完整供应链、形成方案并实施至线路及兼容运力投运；不得仅记录后继续监控。
- 供货率达到或超过50%：不为该指标追加投入，继续检查下一货品。
- 供货率未知：不当作0或达标，仅补查必要原生数据；仍无法取得有效比例时按先修复、无法恢复才暂停规则报告，不用在途观察替代供货率。
使用 get_town_cargo_supply(town) 读取已实机及用户面板核对的供给量、需求量和 supplyRate；不为供货率遍历全部建筑，也不调用 get_town_building_stats 作为替代。该接口未声明统计窗口时如实记 periodKnown=false，保留面板口径。采用语义明确的城市原生供货率，记录数据来源、采样游戏时间和统计期间；只能取得同期间实际供给／需求时明确标为代理比率。半年度交付不能除以年度需求；车辆载货、仓库库存、配置容量及预计交付不能替代城市供货率。

B分支不考虑在途运力：不将已发车、载货、运输正常、预计到货或已建待生效运力折算为已供给，也不从按供货率计算的缺口中扣除；不能以等待到货、完整往返或统计生效为由延后低于50%的优化。此规则优先于历史在途观察和待生效去重规则。保留操作去重：已成功提交的具体建造、购车或分配请求不得重发；未完工程从真实续作点完成，不能重放旧脚本。

以城市供货率距50%的差额确定增量目标；同期间需求量D已知时，供给缺口为D×(0.5-r)，r为当前供货率的小数值。不加入在途供给抵扣。将缺口换算成完整供应链所需的生产与运输能力并留有合理余量；原料、生产、道路和车型调查用于确定如何实施，不另设触发门槛。需求量缺失时不得编造精确数量，先补查必要数据并按可取得的有效数据形成方案；关键数据仍不足时先尝试受支持的替代读取，无法恢复才暂停报告。
- 现金严格高于5000万元：采用积极完整方案，比较更大兼容运力、更高效运输方式和完整配套，可一次配置多车、多站及同一货品所需的多段线路。
- 现金低于或等于5000万元：采用资金可承担的一般完整方案，调整线路、装卸、班次并增配必要车辆、站点、接驳与捷径；同样低于50%即实施，不退回逐车试探。
现金档位只决定实施方式，不改变50%触发条件。首次付费前复核现金；保留支出后严格高于150万元、其他工程承诺及不新增贷款。完整方案资金不足按先修复、无法恢复才暂停规则处理，不以空方案结束。

检查原料、中间品、生产、干线、中转及末端配送，修补限制全链的环节，不只给末端加车。允许在已有授权内增加兼容运力、必要道路及设施；比较实际性能、维护、完整费用和收益，不按车型名称猜测。直升机等方案须包含两端设施、接路、共库、末端配送和维护。替换运力先投运再按已验证入口妥善停放旧车，不自动售车、拆除或撤空服务。公交优化保留在第3项。

增运选型优先级（B分支、第3项及其他增运业务共用）：先比较用更大实际兼容载量的载具替换现有小载具，再考虑追加同类小载具；高资金和一般方案均遵守。核对目标货品的实际载量、班次效率、终端／道路／基地兼容、维护和完整费用，不用目录最大容量代替该货品的可用载量。更大车型确实不可用、不兼容或完整方案不可承担时，记录原因，再采用加车或必要配套方案。

向城市内送货时，同时比较候选的原生噪音、污染及满足同一缺口所需的车辆数和车次；优先容量合适、能减少车次且城市环境负担较低的方案，不只追求单车最大容量。噪音与污染分别记录，不能因低噪音就推定低污染，也不能按车型名称、电动／柴油标签猜测原生数值。无法取得关键比较数据时按必要补查及遇阻规则处理，不编造环境收益。替换时先让新运力投运，再让对应旧运力退出原线并妥善停放；不自动售车、拆除或中断既有服务。此优先级不改变低于50%即优化、B分支不抵扣在途、每轮一目标及资金约束。

完成本轮方案后记录实施结果，城市供货率达到50%才算指标达标。后续轮次仍按当时读取的供货率判断；低于50%时不得仅因上一轮已增运或运输仍在途而跳过。每轮仍最多一个具体目标，不将多个货品打包。
仅当未选定供货率优化目标时，才依次检查以下新增需求、新产业；一般方式不缩减主城新增需求已有的完整供应链建设授权。

B分支续查：主城新增需求→新产业
先读主城原生需求，按真实货品ID去重，与同图同城有效基线比较。首次读取只建基线，同图重载不把全部既有需求当新增；基线更新不丢失未完目标。分类数量、上游原料或固定历史表不能代替城市需求。
忽略已经关闭的产业。
发现新增货品，选定一个并停止后续检查。核对成品来源、必需原料和中间品、生产／库存、运输中转、末端接收。缺运输线路、车辆或可建设的接驳可纳入完整方案，不等于缺生产来源；只有成品厂也不证明全链完整。
主城新增需求工程除资金条件外，不另设规划和建设的授权限制。为满足该货品实际需求，可在全图按完整供应链需要新建或扩建生产工厂，补齐原料和中间品生产、道路、桥梁、隧道、码头、机场、铁路、仓库、客货站、维护设施、地形工程及其他必要建设，配置线路并购置兼容运力；不因城市归属、距离、运输方式、设施数量、已有同类设施或特殊工程类型再次申请。真实生产来源缺口直接纳入完整建设方案，不再因缺少现成产业而停止。资金足够即在已支持接口内实施至配送，不等待50%统计；未知字段、原生碰撞或接口不支持仍如实处理，不把授权等同于技术可行。城市实际收货独立验收。此授权针对主城新增需求，不自动扩展无关产业发展；拆迁、售车、清货等非建造操作仍按各自授权。
未选定新增需求目标时才检查新产业，以原生ID、类型、位置比较有效基线；首次或身份失效后的基线不冒称新产业。能改善主城供应链且资金足够则自动接驳、补原料运输、改线／建线、购车供货；无关产业只记录。已有服务和库存运力去重，不挪空既有服务。
沙子供给允许重复配置设施、新建独立码头或扩建现有码头；比较实际通航、船型、岸上接路、共同库存、维护与完整费用。优先满足需求的小型码头；扩建只有结构预览、缺完整报价或碰撞验证时优先完整原生预览的新建方案。重复设施许可不允许重复提交请求或重建已完成对象。

第3项：供货或公交不足50%时，主动实施完整增量方案

逐货品读取主城实际需求；任一货品或公交指标不足50%即针对该目标处理，不要求同时不足。使用语义和统计期间明确的原生指标；同期间消费／需求或公共交通使用率只能注明为代理指标。半年度交付不能除以年度需求，座位、覆盖、满载或配置运力不能冒充实际运输率。未知不当作0；必要定向补查后仍缺关键指标，按先修复、无法恢复才暂停规则处理。
确认不足后，以一次完整方案补足达到至少50%所需的预计供给或运输缺口，并留有说明依据的运营余量；不默认只加一辆试探、不要求先积累多个统计周期、不以最小投资为唯一目标。可依据当前需求、实际吞吐、库存积压、班次和合理周转粗估配置多车、多站及同一目标所需的多段线路；估算记为估算，不能当作已达标。
货运同时检查原料、中间品、生产、干线、中转和末端配送。优先解决限制全链的环节，允许补充来源、增设接驳、并行线路、增加兼容运力、扩充运输和维护设施；已有授权范围内的生产建设也纳入整体方案。主动比较直达路、捷径及更高效运输方式，不因已有低效线路或同类设施而只做微调；不只给末端加车而保留上游断料。
公交从城市实际出行缺口和覆盖薄弱区出发，可同时规划必要站点、双向或接驳线路、班次和多辆兼容车辆；有依据时采用更大容量或更低噪音车型，配套接路与维护。不只给拥挤线路逐辆加车，也不把覆盖增加称为实际运输率达标。
找到首个有依据、资金可承担的完整方案就直接实施，不默认全图穷举或无限精算。单一货品或公交问题所需的完整工程计一个目标，施工仍串行；无关货品或其他独立问题不得合并绕过每轮一项上限。沿用各工程已有授权，缺少必要权限也按阻碍报告，不擅自扩大拆迁售车等边界。
完整方案资金不足且无可承担的完整替代方案时暂停并报告总费用、可用现金、其他承诺及具体缺口，不拆成只能出库却无法形成有效服务的投入。保留150万元底线、不新增贷款；此项不受5000万元新优化触发值限制。
```
