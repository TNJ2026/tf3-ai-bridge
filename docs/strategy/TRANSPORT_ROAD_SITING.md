# TF3 公路与电车设施选址

更新：2026-10-03。返回[交通设施选址总览](TRANSPORT_FACILITY_SITING.md)。

适用范围、证据分级和统一施工规则见总览；以下位置取舍为规划建议，当前参数须按版本和存档核对。

## 公路客货站、路边停靠点与电车

| 类型 | 优先选址与接驳 | 预留/主要风险 |
|---|---|---|
| 公交/电车停靠点 | 靠近实际出行目标和换乘入口；按行驶方向设置，检查两侧站点和安全可行的步行连接 | 不紧贴容易回堵的路口；留站前后排队与线路调整空间，避免过密停站拉长旅程 |
| 公路客运枢纽 | 多条接驳线能直接到达、换乘步行短的位置 | 预留独立进出流向和更多站位；不要让所有线路挤在一个入口 |
| 货车集货站 | 来源库存覆盖内；覆盖不到时增加真实集货运输，而非假定货物自动跨越 | 保留装卸位、货车转弯及仓库扩建；与工业本体升级空间错开 |
| 城市货车配送站/卸货点 | 覆盖需要该货物的实际建筑，并使回程顺畅 | 按街区分期设置，避免大车绕城区和集中排队；核对设施是否允许装货、卸货及相应货类 |
| 电车车库/接入设施 | 接入实际电车网络，便于投入运营且不干扰主线 | 模式、电气化、出入方向及维护覆盖分别验证；电车轨道与普通道路连通不是同一个条件 |

本项目总部/公路购车车库的固定规则仍有效：总部优先城市中间道路末端附近的道路侧边，入口面向既有道路，不占据尽头正前方；公路车库优先城市与外部道路连接口路边，首个符合接入、碰撞和升级条件的候选即可，不反复全城评分。专用维护设施按线路覆盖另选，不受购车车库默认位置束缚。[固定选址规则](../guides/AGENT_PLAYBOOK.md#34-总部与公路车库的固定选址规则)

总部必须连接城市道路：入口面向末端路段的侧面，留出道路继续延伸的空间；规划时检查真实入口通达，建成后读回入口到道路的实际路径。靠近道路或建筑预览通过不足以证明连接成功，未确认通达的候选不得标为可施工或验收通过。

来源与未验证范围见[总览的来源说明](TRANSPORT_FACILITY_SITING.md#来源与待核对范围)。
