# TF3 机场与直升机设施选址

2026-10-05 用户修订：取消独立的双停机坪生产集合类型。城市与陆上生产点统一采用完整城市集合：直升机场（使用自身两个降落平台）、仓库、货车站、客车站、公路车库及组内道路。优先复用，不按城市或工厂数量固定新建；捕鱼港口六设施集合保持不变。当前地图及已有设施、线路不改动，此次仅更新文档。

更新：2026-10-03。返回[交通设施选址总览](TRANSPORT_FACILITY_SITING.md)。

适用范围、证据分级和统一施工规则见总览；以下位置取舍为规划建议，当前参数须按版本和存档核对。

## 固定翼机场与简易机场

**优先位置**：城外较平缓、少拆迁、土方较小且有连续扩建空间的地区，并能用可靠接驳连接客流或物流来源。机场面积较大，声誉预览应在候选比较阶段检查，不能等道路全部铺好才发现需要大规模平整。

**客运**：比较“到机场接驳＋候机/等待＋飞行＋目的地接驳”的完整旅程。机场远离住宅有利于减少附近噪声暴露，但过远会延长接驳；距离不是唯一标准。

**货运**：货机兼容、货运终端和仓库覆盖必须同时核对。仓库与公路/铁路接驳应形成实际中转，保留批量卸货后的集疏运能力；避免只建客运模块却期待货运正常工作。

**扩建**：按当前原生机场模块预留跑道延长/新增方向、滑行道、停机位、航站楼/货运区、机库及外部接驳。先核对目标飞机与跑道/终端允许的运输模式和容量，不套用前作固定跑道门槛。未查明的风向、净空和现实航空间距不作为游戏硬规则。

**维护**：检查实际机库模块位置的维护覆盖，尤其扩建后新增停机位是否仍被有效服务。无限金钱也应分期扩容，以实际等待和吞吐判断瓶颈。

## 直升机场与小型直升机坪

**大运量分流（2026-10-04 用户规则）**：陆上两端优先让直升机场自身两个降落平台分别承接运输线路；捕鱼港口继续使用两个独立停机坪，避免运量全部集中在单线或单平台。规划须明确实际终端分配、运量和运力，运行后检查平台使用及排队；具体要求见[双平台分流规则](../guides/GROUPED_CONSTRUCTION_WORKFLOW.md#大运量航空货运的双平台分流)。

**直升机场（heliport）兼有客运、货运、购机和维护能力，连接道路后可作为航空客货线路终端，不必在旁边再配一座小型停机坪。** 2026-10-03 用户纠正此前将其主要视作购机维修基地的规划；本地原生 `air/heliport/heliport.script.lua` 也明确配置终端 `passengers=true`、`cargo=true`。优先复用直升机场自身终端，只有覆盖或吞吐确有不足时才另设停机坪。

道路接入、客运步行通路、货物库存覆盖与线路装卸配置仍分别验收；接路不表示货车自动获得可装卸的公路终端，也不表示货物会自动送达全城。已有线路使用旁侧停机坪时，先规划迁线并验证运输，再按授权清理冗余设施。

**客运选址**：靠近目标客流和短距离接驳，比较噪声、地形和扩建余量。小占地不等于适合塞进每个住宅街区。

**货运选址**：优先围绕共享仓库布置直升机场自身货运终端（或小型停机坪）和货车站，使两站的货物覆盖都包含同一个仓库库存。农场不在停机坪覆盖内时，用货车从农场运到中转仓，再由直升机取货；目的地按同样方式换装配送。仓库既要满足当前重叠覆盖，又不能占用停机坪扩建、接驳或自身扩容空间。

当前小型停机坪原生定义的货站覆盖半径为100米，购机基地站点为175米；购机基地另有800米维护范围。**站点货物覆盖与飞机维护范围是不同概念**，不得用800米判断仓库可以装卸。实际模块和范围中心以实时组件为准。[本地参数证据](../../exports/transport_siting_20261003/native_evidence.json)

徐州运行记录已验证两端各一座500容量仓库、2辆货车、2架H-21组成完整供给链；这是布局可用的实例，不是其他地图通用坐标或运力配方。参考[运行验收记录](../../exports/xuzhou_heli_build_20261003/execution_record.json)。

### 城市外500米的暂定选址基准

**2026-10-04 无限资金模式更新：**城市按完整城市集合规划，放在当前建成区外缘 **500 米之外**，按外缘到集合最近建筑边界计；陆上生产设施附近也使用完整城市集合，不再默认使用双停机坪集合，不设到生产设施的固定距离门槛。该场景以[集合选址规则](../guides/GROUPED_CONSTRUCTION_WORKFLOW.md#无限资金模式的默认集合选址)为准，优先于下述较早的“约 500 米”偏好。仍检查覆盖、接驳、城市扩张、噪声和污染，距离规则不等于噪声安全保证。

2026-10-03 用户确认：后续直升机场（heliport）选址，暂以**当前城市建成区外缘到机场最近边界的平面最短距离约500米**作为初步基准。不是从市中心、机场中心或市政区域边界计算，也不是必须精确满足的固定距离。

| 用途 | 选址与接驳要求 |
|---|---|
| 货运为主 | 优先城市外围对外道路附近，结合共享仓库、货车站和短途配送布局，避开住宅 |
| 客运为主 | 预留公交或电车接驳，比较接驳、等待、飞行和目的地接驳的完整旅程 |
| 客货兼用 | 优先商业或工业一侧的城郊，核对客运通路及货车进出，减少相互干扰 |

选址同时参考[城市发展范围预测](../guides/AGENT_PLAYBOOK.md#35-城市发展范围预测)：标出当前建成区、近期扩张估算区和长期预留区，尽量避开预计住宅扩张方向，并保留机场升级及接驳空间。若500米附近的候选与扩张预留、地形或接入要求冲突，应说明原因后调整位置，不为满足距离强行施工。

**500米是暂定规划偏好，不是官方最低间距，也不是已经验证的噪声安全距离。** 运行后应结合噪声分布、城市评分和接驳效率调整。官方说明住宅对噪声敏感，而污染按整个市政区域统计；这段间隔不能保证消除污染。[官方城市评分说明](https://www.transportfever3.com/news/dev-blog-episode-4-tycoon/)

站点覆盖范围和维护范围均不能当作噪声安全距离。本规则不自动授权搬迁已有机场或改动已有线路。

### 直升机场选址与道路同步规划

2026-10-03 用户确认：**先预选直升机场位置，同时规划接入道路；机场与道路方案都可行后，才确定最终选址。** 不先锁定或建成机场，再临时寻找接路办法。

1. **预选位置**：按当前城市建成区外缘约500米基准筛选，结合城市发展范围预测，避开预计住宅扩张方向，并检查地形、噪声与污染取舍。
2. **同步规划道路**：选取可用的既有道路接入点，优先沿末端方向直线延伸，必要时用平滑曲线连接。明确机场入口位置、接入方向、坡度和避障走廊，避免为追逐预选点产生绕路、急弯或回头弯。
3. **联合调整布局**：一并核对机场朝向、出入口、升级占地和道路预留；货运时布置共享仓库及需要的货车站，确认双方终端覆盖同一库存。仓库本身无需接路；优先使用机场自身客货终端，不默认加建旁侧停机坪。客运时规划步行通路及必要的公交或电车接驳。
4. **可行后定址**：道路或设施任一方案不可行时，返回调整位置、朝向或接入点。规划成果须包含机场坐标与朝向、道路走向及接点、配套设施、升级预留和待验收项，不能只交付一个机场坐标。
5. **分阶段预览、施工与验收**：联合规划通过后，按原生接口和实体依赖安排施工阶段。依赖设施生成端口的接路，应在设施建成后重新解析实际端口，再做道路预览、单次提交和通路验收。施工可以分阶段，选址与接路规划不能割裂；规划可行也不能替代每次提交前的实时原生预览。
