# TF3 交通设施选址总览

更新：2026-10-03。分类整理；沿用同日研究和验证证据，本次仅调整文档。

## 依据和使用方法

本文覆盖客运/货运铁路站、公路客货站与停靠点、电车设施、客货码头、船坞、固定翼机场、直升机坪、购机基地以及道路/铁路/船舶维护设施；仓库作为货运中转必要配套一并讨论。模块、年份和模组不同，不能用一个固定半径或占地替代实时预览。

证据分三层：**官方机制**引用 TF3 官方网站或 API；**本地确认**来自当前安装资源及项目运行记录；**规划建议**是据此推导的布局选择，本文各设施的“优先位置、预留与避坑”均属于建议，不是原生硬性建造限制。没有把 TF1/TF2 Wiki 或第三方攻略中的半径、跑道长度、维护规则当作 TF3 事实。

官方已说明：旅程时间、舒适度和车辆维护会影响经营效果；因此选址需要连同线路和接驳评价。[官方基础设施介绍](https://www.transportfever3.com/news/first_look_episode_3_infrastructure/)

官方也明确，砍树和大规模土方会影响声誉，住宅对噪声敏感，污染按市政区域统计。把枢纽放在城边可能减少住宅附近噪声，却不能自动消除该市政区域的污染。[官方城市评分说明](https://www.transportfever3.com/news/dev-blog-episode-4-tycoon/)

施工流程遵循[执行手册](../guides/AGENT_PLAYBOOK.md)，初筛使用[批量选址接口](../reference/SITE_SELECTION.md)，接口限制见[设施接口](../reference/FACILITY_SUPPORT.md)。用户指定的无限金钱只免除成本取舍，不推定声誉、维护、时效、噪声、容量或寻路规则也关闭。

## 所有设施共同的选址顺序

1. **先确定服务对象**：客运列出住宅、工作/商业区和换乘目的地；货运列出实际货物、生产端、收货端及每段运输方式。先判断是否需要中转，避免为了建枢纽增加不必要的运输段。
2. **先核对硬条件**：当前年份/许可、模块与载具兼容、陆地/岸线/水域适用性、地形、碰撞、接入口、可用终端。硬条件失败的候选不进入评分。
3. **看完整旅程**：步行或集货、等待、干线、中转、末端配送、返回路径；比较实际可行路径，不只量两座城市或设施的直线距离。
4. **留出升级和通道**：当前建筑之外，还要预留站台延长、股道/泊位/装卸位增加、仓储扩容、维护、路口、引道及岸线/航道。尚未原生预览的预留区标为估算。
5. **比较环境影响**：读取 `check.reputation`（仅在 `available=true` 时引用，单位百分点），分城市检查原因。它是即时施工界面口径，不是最终城市声誉，也不包含运营噪声和污染。运行实例未加载新字段时记“未知”。
6. **尽量少改现有网络**：优先利用平缓开阔地和已有连接口，避免大填挖、密集拆迁和复杂接线。无限金钱下仍要考虑施工声誉、通行冲突和扩建难度。
7. **按实际运输验收**：设施建成和车辆无寻路错误只是中间状态，最终检查乘客完成旅程或货物被末端接受/消费，以及维护状态在完整循环内是否恢复。

候选记录建议使用下表；不采用未经校准的统一权重或“离住宅固定多少米”的规则。

| 项目 | 每个候选应记录 |
|---|---|
| 服务与覆盖 | 目标、客/货类型、覆盖到的实际建筑/库存、未覆盖部分 |
| 接入与寻路 | 出入口、终端、去程/回程、车库或船坞到线路首站路径 |
| 效率 | 绕行、换乘次数、预计等待、装卸/排队瓶颈；估计与实测分开 |
| 施工影响 | 声誉可用性、各城市扣分及原因、拆迁、土方和碰撞 |
| 维护 | 匹配运输模式、范围中心与半径、维护池、实际经过/停留位置 |
| 扩建 | 当前占地、下一阶段模块占地、引道与升级受限方向 |
| 结论 | 推荐原因、拒绝原因、尚待原生预览或模拟验证的事项 |

## 从选址到验收的输出要求

每类设施至少给出：服务目标、候选坐标/朝向、接入端口、实际覆盖对象、配套仓库/接驳、维护方案、下一阶段扩建方向、声誉预览和尚未验证项。若首选符合项目固定位置规则，无需无止境比较全城。

只规划时输出方案，不建设。获授权施工后按当前会话重新解析实体、原生预览、单次提交、读回；未知碰撞、超时、部分成功先查现场，不重发。停靠点使用当前 `build_street_stop`。不为取得评分而运行历史危险替换提案。

货运至少观察一轮“来源装货—换装—目的地卸货/消费”；客运观察实际乘降与旅程；维护观察周期内恢复。`noPath=false`、`built`、静态`verified`及覆盖相交不能替代运行验收，更不能保证长期模拟安全。保存使用原生存档接口，保留施工前版本。
