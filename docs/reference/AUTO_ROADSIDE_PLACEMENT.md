# 自动沿路选址与道路中段接入

入口：`scripts/place_roadside.py`。主机实现为 `frontage_planning.py` 和 `frontage_workflow.py`。2026-10-13 高差优化需要加载新版桥接，运行时须提供 `frontageHeightPolicy=native-foundation-alignment-v1`；仅更新磁盘文件不会改变游戏内已加载的代码。碰撞、pending 和单次令牌保护保持。

## 输入与行为

- 指定当前道路 `--edge` 与 `--param 0.37`，或给出 `--x/--y`，自动解析150米内最近普通道路及曲线投影点。编号必须与本次 `--map-digest` 绑定，不从旧报告复制执行。
- 支持 `road_depot`、`tram_depot`、`cargo_station`、`passenger_station`、`heliport`、`helipad`；车站支持 `--size 1|2|3`。
- 沿原生三次 Hermite 曲线计算位置、真实切线和朝向，默认先比较左右两侧，再有限比较邻近位置，最多12个候选。`--exact` 禁止沿路移动候选，`--side left|right` 固定方向；左右按原路 node0→node1 定义。
- 车库/车站从当前地图同资源、同类型、同规模设施的真实外部端口反算局部入口，不复用历史实体。没有匹配原生样本时明确报未知，不猜入口。
- 直升机设施从本地原生资源读取碰撞轮廓并记录文件哈希，结合当前道路所有车道宽度及偏移计算入口侧零间隙退距；不使用吸附点或固定28米/62米常量。
- 初筛道路占地、已有建筑、未知/水域地形；基础调整量记录为参考，不再以2米阈值淘汰。模块化车站的占地包络是保守估计，非原生碰撞结论。候选还做自然高程下的原生建筑预览，此初筛不是最终基础高程验收。明确碰撞时可继续下一候选；接口错误、超时或不明结果立即停，不重发。

## 高差处理（2026-10-13）

公路车库、电车库和街道车站的联合接路不再以0.25米入口差值直接拒绝。发现原生入口与现有路口高程不一致时，保持道路原高程，按实际差值调整一次建筑基础，再重新发现原生入口并执行最终原生预览。1厘米是校正收敛容差，不是建筑地形限制；未收敛、未知入口、碰撞及未知移除仍拒绝。显式基础高程只要求有限数值，不再限制距自然地面2米；最终可行性由原生预览判定。

普通新建道路图及路网取消12%固定坡度拒绝，必须通过原生预览。含旧路删除/替换的道路图仍只有结构预览，因此其中新增陡于12%的路段仍拒绝：须先完成必要切分，再单独原生预览新路段。不要恢复已知会断言的替换图原生预览路径。道路报价、令牌、读回及实际接路验收不变。

此版本已完成四类设施约3～3.83米正负高差自动校正建造、48项有向通路，以及20%新路施工和4项通路检查。自动选址-2.55米候选进入规划但未提交；仍需后续联合预览。详见[高差优化记录](../../output/frontage_height_20261013/RESULT.md)，结果不代表任意坡度、实际行车或长期模拟均已验证。

## 规划与施工

默认只规划，不修改世界；预览调用会使用既有接口操作额度。一次性脚本本身不隐式重置；执行者在额度用尽或不足时按[长期授权流程](OPERATION_QUOTA.md)自动重置，无需再次申请，重新预览后从实际续作点继续，不重跑已施工步骤。加入 `--build --budget <金额> --backup <槽名>` 才施工，仍默认保留150万元现金。输出文件 `--output` 必须不存在，持久记录每次请求ID、原生回执及续作点，绝不覆盖旧尝试。

公路类按以下依赖实施：

1. 完成本次地块与建筑初步原生预览，只允许尚未绑定造成的**目标道路自身碰撞**进入后续接路设计；其他建筑、道路、警告及未知移除阻断施工。
2. 按原曲线在任意合法中段参数处纯切分，独立读回新两段道路及新节点。不得把结构预览标成原生碰撞预览。
3. 使用刚读回的节点和自动计算的建筑位置，执行 v5 最终联合原生预览，取得有效价格后单次提交。
4. 独立核对真实共享入口，并检查两类兼容交通模式的12项有向原生通路。实际行车与长期模拟不由此证明。

直升机设施无需为了选址切分道路；原生建筑预览、单次提交后读取 `automaticRoadLinkObserved` 等真实连接证据。

**切分报价边界：** 现有道路图切分预览只有结构检查，没有原生价格。默认施工入口在此停止。仅在明确允许未知切分费用的场景（例如用户授权任意建拆的废弃测试地图）可传 `--allow-unpriced-split`。此时记录 `cost=null`、`fullCostKnown=false` 和 `budgetGuaranteed=false`，不可称工程总价已核实；建筑仍需有效原生报价及余额检查。不能把该参数当作普通限额任务的默认选项。切分后建筑拒绝时保留 `road_prepared` 续作点，不再切另一条路或重复原操作。

## 实际范围

“任意位置”指普通道路中段的合法曲线位置，无需预先人工建好二度节点；不是在十字路口中心、桥隧、冻结内部道路、带对象道路或自定义信号处强制塞入建筑。切分参数仍受0.05～0.95及子段至少5米保护。路口附近可在选中支路的合法中段找候选；不更改路口原有配置。

宽路、急弯、建筑大模块或模组覆盖资源仍以最终原生预览为准，不能承诺任意组合可放置。未找到候选会保留具体拒绝原因，而非取消保护。
