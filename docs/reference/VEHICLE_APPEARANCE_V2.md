# 载具外观 v2

接收器源码版本 **0.12.24**，能力标记 `vehicleAppearanceVersion=2`。实现与280项离线测试完成。2026-10-16已部署并通过原生读档重载，实时心跳和命令表确认v2生效；功能效果仍待实机验收。v1 整车改色已经实测，不代表以下新功能也已实测。

## 持续跟随线路颜色

`vehicle_color_sync(action="start", lines=[线路ID], interval_seconds=30)` 启动 Python MCP 服务内任务，10～3600秒一轮，最多16条指定线路、每线最多64辆车；读取线路 COLOR 及当前车辆列表，自动覆盖新加入车辆和线路颜色变化。颜色已一致时不发送修改。没有改色遮罩的车型跳过，不尝试换车型。

`vehicle_color_sync(action="status")` 查看状态及最近改色记录，`action="stop"` 停止。停止会等当前已发送操作终结，不取消或重复已发命令；后续车辆不再执行。会话变化、未决请求、未知数据或改色失败会停止并留下错误。原生修改同时检查预期线路归属，避免把已经转线的车按旧线改色。

只有显式 start 才运行；本轮没有启动同步。服务断开/重启后不自动恢复，需要重新 start，不是游戏离线也运行的系统服务。配置和状态保存在 `<TF3_MCP_DIR>/appearance_sync.json`，每次改色沿用独立持久 journal。启用后会覆盖选定线路车辆的手工配色及逐节配色，使用逐节颜色前应停掉相关同步。

## 恢复默认色

`reset_vehicle_color(vehicle)` 使用游戏默认色 RGB `(-1,-1,-1)`，通过专用入口允许此标记；普通 RGB 接口仍只接受0～1。保留车型、线路与其他配置，沿用原生 pending、逐车日志和独立颜色读回。此前 v1 只能通过读档恢复默认色的限制，在 v2 由此入口补足；本轮只有离线验证。

## 已安装涂装和每节车厢

1. `list_vehicle_liveries(vehicle, part=0)` 枚举当前部件原生变体组中已加载的模型。分组是候选发现，不是兼容证明。
2. `preview_vehicle_appearance(vehicle, part=0, model="modid::/path/model.mdl")` 预览涂装切换；或者传 `r,g,b` 修改这一节，或者 `reset=true` 恢复这一节。三者只能选一个，part 从0开始。
3. `commit_vehicle_appearance(preview_token, max_cost, cash_floor=5000000)` 先保存并验证备份，然后一次提交；独立读取外观。预览有效60秒，车辆/配置/价格变化则拒绝，重新调查后再预览。

逐节修改采用原生 `makeVehicleReplaceCmd`，不是直接改引擎内存。要求**游戏暂停、车辆在车库且无已装货物**；不自动回库、卸货或停车。复制全部部件、朝向、货舱配置、维护值、购买时间及组合信息，仅改变选定部件模型或颜色；回调比较整个配置，不一致保留 pending，禁止自动重试。对于原生会重写这些字段的车型，接口可能拒绝验收，需单独调查，不能默认放宽为成功。

涂装切换还要求机械元数据严格相同（排除描述、可用年份、价格和外观分组/遮罩字段），目标模型在当前年份可用；不将速度或容量不同的车型当成涂装。无法证明兼容时拒绝。所有车型/固定编组并非均已支持。

费用采用全部部件重新采购的原生报价总和作为保守上限，不计回收抵扣；它不是精确交易报价，也不承诺逐节改色免费。预算必须覆盖此值，付款后现金严格高于所填底线，且底线至少500万元。原生兼容性最终由游戏决定，预览明确返回 `nativeCompatibilityVerified=false`。主机要求同会话、120秒内且文件签名和 SHA-256 不变的已验证备份；备份名称本身不能替代证据。

## 图片、Logo、广告和文字涂装

`build_vehicle_repaint` 是本地资源生成工具：输入源 ZIP、模型条目、完整原模型资源名、albedo 贴图条目、新目录、独立 mod_id 和标题，再提供完整替换图片或 overlays。

```json
{
  "overlays": [
    {"image": "D:/Art/logo.png", "box": [100, 200, 500, 400]},
    {"text": "CITY BUS", "box": [100, 410, 500, 460], "color": "white"}
  ]
}
```

box 是**原车 UV 贴图的像素坐标**，不是车身坐标；位置必须依据模型 UV 确认。可以换完整贴图，或合成透明Logo/图片/广告/文字。输入源图尺寸与原图一致，最高8192像素边长；生成 TGA 和 PNG 预览。现有颜色遮罩仍生效，可能影响Logo显示色，应在模型编辑器验证并选择适当默认色。

生成器只读取原档案，生成独立 mod.json、元信息、mdl、改动材质和贴图；重新关联所有匹配的 LOD 材质。其他网格、动画、材质及贴图引用原资源；不会覆盖原车、执行输入模型 Lua、订阅或上传模组。当前支持同一 ZIP 内、相对路径引用的目标材质和常规 albedo/albedoOpacity sampler；不支持任意动态 Lua 材质脚本。外部目标材质需先准备包含依赖的资源包。

生成结果是可继续编辑的本地涂装源包，**不是已经在游戏中安装和应用的车辆**。仍需用模型编辑器检查UV/LOD、生成UI图标，按游戏流程验证/安装并重新加载资源，再通过涂装列表和配置替换接口应用。游戏并无已确认的单车任意 PNG 热贴接口。
