# 既有道路电车轨道与公交车道升级

当前 no_gui 入口：`preview_road_upgrade(edge, street_type)` → `commit_edge_edit(preview_token)`。使用当前真实道路模板替换整段道路，保留几何与端点；不是任意逐车道编辑。提交前备份，预览令牌单次使用，建后须独立读取新边ID与配置。

## 已验证范围

2026-10-15 当前地图上分别将三段普通中型城市道路升级为：

| 目标模板 | 验证结果 |
|---|---|
| `town/town_new_medium_tram_electrified` | 三段共300米升级成功，电车、电气化电车、普通汽车双向通路通过 |
| `town/town_new_medium_bus` | 三段共300米升级成功，公交、货车、普通汽车双向通路通过；公交模板外侧车道允许公交和货车，禁止普通汽车，内侧保留普通车道 |

六段升级均保持原端点与几何，24项原生有向查询通过。已保存、保持暂停，未实车试跑或重载。见[完整实测与证据](../../output/road_lane_upgrade_20261015/RESULT.md)。

## 当前限制

- 升级预览仅结构检查，`costAvailable=false`；没有完整原生报价及碰撞预览，不能标为原生预览可施工。原生提交不会强制忽略碰撞，受预算约束任务仍须满足其报价规则。
- 仅普通地面道路；拒绝桥隧、建筑自带道路、带停靠点或其他边对象的道路。
- 当前按道路模板选择电车或公交配置，尚未验证同时包含两者的组合模板。
- 道路ID可能因替换改变；刷新引用后再查询路口路径，不能复用旧边ID。
