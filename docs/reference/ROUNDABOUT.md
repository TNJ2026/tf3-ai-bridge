## 规划与执行

1. 先按用途、合计车流及空间选择道路和规模；环道必须具有一致行驶方向。道路宽度或高速名称不能替代容量与速度分析。
2. 整体设计环道和各出入口。优先平滑曲线及合理接入方向，避免急弯和过密入口；保持节点、切线与合法车道转向相容，不能只凭视觉相交判定已连接。
3. 每个入口核对环内继续、出环、入环三类通路，以及逆向拒绝。涉及额外车道时逐车道复核，不把本例单车道结果外推。
4. 独立读取原生 `TRANSPORT_NETWORK`，按几何端点匹配环内与引道交通边，确认实际连接。流量控制不属于当前需求，不要求调整优先权或信号配时，不以动态让行表现判定施工失败；不可用不透明 userdata 当成空网络。
5. 保留施工前存档，重新解析现场、预览、单次提交、读回并保存。复用既有环岛时不为测试重复建设。无需为流量控制追加试车；如因其他已授权任务临时调配车辆，完成后恢复原线路。
